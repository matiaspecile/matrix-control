Forge Report — skins V1 / modèle SSOT

Matrix-Control · 21 oct. 2026 · slug mode-dev-skins

Outcome stamp
Résultat : idée durcie. Le chantier V1 n’est plus « Skin Studio fidèle » ni « mode Dev d’abord », mais une refonte modèle SSOT dans Matrix-Control (deadline 15 nov., parque total sinon), éditeur et peaufinage Black/Cream conditionnels ensuite.

Décisions verrouillées

  • Skin Studio HTML gelé (sidebar PhotoCraft réutilisable plus tard).
  • Modèle d’abord : palette SSOT + mappings + états sur toute la GUI utilisateur V1.
  • Branche dédiée ; Black/Cream actuels suffisent pour alpha/V1.
  • Deadline modèle : 15 novembre 2026 — sinon parque total.
  • Parité migration « assez bonne » (pas pixel-strict).
  • Forme éditeur (in-app vs télécommande) reportée après la porte modèle.
  • Noël adaptatif : viser fierté si vitesse OK ; filet = modèle seul ou parque.

Rejeté — pourquoi

  • GUI pixel-près dans le navigateur — rasterisation / layout / double moteur.
  • Éditeur avant modèle propre — vernis sur dette.
  • Shrink merge ou alpha retardée — contredit le filet Noël.
  • Contributeurs Dev comme exigence V1 — bonus seulement.

Faiblesses encore vivantes

  • Porte « toute GUI V1 » en ~3,5 semaines à temps partiel : ambitieuse.
  • « Assez bonne » parité à préciser en spec (exemples concrets).
  • Éditeur + peaufinage Black/Cream peuvent ne pas arriver avant Noël.
